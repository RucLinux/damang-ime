# damang-ime
大蟒是用C++开发的一套自研中文输入法，拼音和五笔 86 走同一套引擎。Windows 10/11（x64）走系统输入法，Linux 桌面（含 Deepin）走 Fcitx5，也可以选 IBus。两端的打字习惯和配置项是对齐的。界面上显示「大蟒输入法」。  适合日常写字，也适合五笔录入。全拼、简拼、模糊音都有；选过的词会记在本机，越用越靠前。五笔按 86 简码优先，和拼音词库分开，不会串码。候选条是横排，绿色底是首选，∨ 展开更多，右侧四色点打开设置。皮肤有纸白、夜墨、琉璃。中文默认全角标点，可以出简体或繁体。用户词和调频都在本机。打字效果对标的是微软拼音、微软五笔、微信五笔几个输入法，界面美观大方。  

## 常用操作：

空格上屏首选，数字键 1–9 选词，- / = 或翻页键翻页，Esc 清空
单独按一下 Shift：中文 / 英文
F4：拼音 / 五笔
Shift+空格：全角 / 半角
F9：首选旁边显示全拼或全码，方便练习

## 能做什么

- 全拼、简拼、模糊音；选过的词记在本机，越用越靠前
- 五笔 86，简码优先；拼音词库与五笔码表分开，不串码
- 中 / 英：单独按 Shift；拼音 / 五笔：F4；全角 / 半角：Shift+空格
- 候选条横排，绿色底为首选；∨ 展开更多候选，四色点打开设置
- 皮肤：纸白 / 夜墨 / 琉璃；可输出简体或繁体

## 支持的系统

在这些系统上从源码编译。安装包不能跨大版本通用：deb 在 Debian/Deepin 上打包，rpm 在 Fedora 上打包。

| 系统 | 版本 | 状态 |
|------|------|------|
| Windows | 10（21H2 及以上）、11，x64 | 支持 |
| Ubuntu | 22.04、24.04 LTS | 支持 |
| Debian | 12 及以上 | 支持 |
| Deepin | 25 / 25.1 | 已在 25.1 上安装使用 |
| Fedora | 39 及以上 | 支持 |
| RHEL / CentOS Stream | 9 | 依赖包名与 Fedora 相同，开发源需自行打开 |
| Arch、openSUSE | 当前滚动版 | 需自备同名开发包，未逐版本验收 |

架构按编译机决定：只在x64 下打包，arm装不了。全屏游戏、系统安全桌面不保证可用。个别程序在 Wayland 下的候选条行为跟桌面环境有关。
